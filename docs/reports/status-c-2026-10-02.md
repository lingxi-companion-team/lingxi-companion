### 4.3 接口协议（`common/agent_base.py`，三方共用）

```python
class PerceptionAgent(ABC):
    agent_id: str  # 必须是 AGENT_EXPRESSION 或 AGENT_BEHAVIOR

    def warmup(self) -> None: ...
    def infer(self, frame, ts, frame_id) -> PerceptionResult: ...  # 不得抛异常
    def close(self) -> None: ...


class EnvAgent(ABC):
    agent_id = "env"

    def warmup(self) -> None: ...
    def assess(self, frame, ts, frame_id) -> EnvContext: ...  # 不得抛异常
    def close(self) -> None: ...
```

两条硬约定：**`infer()` / `assess()` 不得抛异常**（内部失败降级为 `UNKNOWN` / 中性 `EnvContext`）；
降级时的中性 `env_score` 取 `weights.e0` 而非 0.5 —— 取 0.5 会因 $0.5 < e_0$ 偷偷假设环境很差，
把判断权单方面让给行为通道（`fusion` 侧有一条对称的实现，两边必须给同一个先验）。

2. 提供行为侧边界场景（融合冲突、协商拒判、时序抖动）—— mock 目录由 C 牵头，但**场景要 A 给**；

## 7. 本轮修掉的两个真问题

### 7.1 隐私承诺文案与服务端行为不一致

旧文案「仅对同学隐藏（**教师仍可见**）」是 v7 的语义（教师可绕过个人开关）。
v8 删掉角色分支后，同一句话变成**把保护范围说小**的误导性承诺 —— 用户以为老师还能看到，于是不敢关。
已改为「不向房间公开我的状态（仅本人可见）」，并**提取为单一来源常量**放在
`app/present/visibility.py`（规则旁边），配套 3 条 CI 守卫：不得出现任何角色词、
必须说清作用范围、**并真的跑一遍 `visible_to` 验证「仅本人可见」不是空话**。

### 7.2 压测预算被覆盖率插桩打穿

同一台机器、同一条测试，唯一变量是 `--cov`：

| 运行方式 | 串行链路单帧中位耗时 | 预算 20 ms |
|:--|:--|:--|
| 不带 `--cov` | 2.02 ms | 通过（10 倍余量） |
| 带 `--cov` | **22.05 ms** | **超预算 10%** |

`coverage` 的逐行追踪让纯 Python 执行慢约一个数量级。而压测里有一条预算
**是从产品指标推出来的**（`1000 / target_fps`）—— 在插桩下量它，等于**用一把被拉长的
尺子量产品指标**：要么随机变红，要么为了让它变绿而把产品指标改松。

**修法：分开跑，而不是放宽预算。** CI 的主步骤带 `--cov` 但 `--ignore=tests/stress`，
紧接着一步**不带插桩**专跑压测；两步在**同一个 job** 内，所以压测失败照样会让
`pytest (3.x)` 这个 required check 变红。副作用是好的：主门禁从 4 分 10 秒降到 **44 秒**。

### 10.4 依赖清单收敛为两份（甲类改动）

10.2 描述的删除经 PR #15 合入 `develop`（merge commit `e262f22`），
CI 五道门禁全绿；用例 **856**、覆盖率 **96.90%** 均与 10.2 的预测一致。

紧随其后的一次**甲类**改动（`pyproject.toml` + `.github/`）做了两件事：

1. **`requirements-web.txt` 退役**，`flet[web]` 并入 `requirements.txt` 与
   `pyproject.toml` 的 `[project] dependencies`，由「可选依赖」升为**正式依赖**。
   理由：v8 起 `app/web/` 是**唯一**产品界面，前端成了照 README 走一遍的必经一步 ——
   再把它藏在第三个清单里，只会制造「按文档装完却起不了产品界面」的坑。
   **CI 行为不变**：它依旧只装 `requirements-dev.txt`，所以 `app/web/*`
   的 `omit` 依然必要，只是理由从「flet 刻意不进 CI」改成
   「CI 从不为任何运行时依赖付安装成本」。

2. **覆盖率 `omit` 由 2 条缩为 1 条**（删掉指向已不存在路径的 `app/client/*`）。
   这是**删路径，不是放宽判定** —— 少掉的那条指向的代码已不在仓库里。

就能把工作记忆目录推进公开仓库。已把 `\.workbuddy-ai` 并入正则。
